# Luis Córdova

Construyo con IA sistemas que le quitan trabajo manual a un negocio: automatizaciones, mini apps, agentes y skills para Claude Code.

Herramientas: Claude Code, Cloudflare Workers, APIs y webhooks, MCP, Make, n8n y Zapier.

## Proyectos públicos

- **[relevo](https://github.com/luiscordova-dev/relevo)**: agentes de WhatsApp con Claude Code, del cero a producción.
- **[traducelive-community](https://github.com/luiscordova-dev/traducelive-community)**: extensión de Chrome que dobla y subtitula videos en vivo en 47 idiomas.
- **[agente-viral](https://github.com/luiscordova-dev/agente-viral)**: encuentra los videos virales de un nicho y los deja analizados en Notion.
- **[fabrica-carruseles](https://github.com/luiscordova-dev/fabrica-carruseles)**: genera carruseles de Instagram con tu marca y los publica.
- **[50-anuncios](https://github.com/luiscordova-dev/50-anuncios)**: skill de Claude Code que escribe 50 anuncios en 10 ángulos.
